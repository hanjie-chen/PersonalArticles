# Repository Guide

## Read First

Start with the root `README.md`. Before creating, moving, or revising content in a directory, read the nearest `README.md` in that directory or one of its ancestors below the project root, if any.

## When Working with Content

- Preserve the scope and level of completeness of drafts; do not turn notes or fragments into polished articles unless explicitly asked.
- When adding structure, keep related points together and use short, descriptive headings. Prefer English headings when practical, but use Chinese when it fits the topic more naturally.
- Use Chinese, English, or both in the body, whichever explains the topic most clearly.
- Format notes as `__template__/note.md` shows.

## Content Placement and Naming

- Use directory paths as taxonomy: choose a content file's location by subject, with each directory representing a narrower topic.
- Use short English file names with lowercase words separated by hyphens (`-`). Let the path provide context instead of repeating information from parent directories.

For example, prefer `code/python/package/flask/basic.md` over `code/python/package/flask/python-flask-basic.md`.
